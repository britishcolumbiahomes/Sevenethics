# Sevenethics

A sandbox repository for learning and experimenting with [Claude Code](https://docs.anthropic.com/en/docs/claude-code).

## Purpose

This repo serves as a safe environment to explore Claude Code's capabilities, including:

- Writing and editing code with AI assistance
- Running commands and debugging issues
- Working with Git workflows (branches, commits, pull requests)
- Experimenting with Claude Code tools and features

## Getting Started

1. Open this repository in Claude Code
2. Try asking Claude to help with a coding task
3. Experiment freely — this is a sandbox!
